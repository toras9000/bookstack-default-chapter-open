# BookStack Customize - Open the chapter list by default

It uses a [logical/visual theme system](https://www.bookstackapp.com/docs/admin/hacking-bookstack/) and redirection to achieve pseudo permalinks to each entity.  

When a book is displayed, the chapter page list expands by default.  

This module replaces the existing template rather than adding to it.  
Be careful to avoid incompatibilities caused by version differences.
